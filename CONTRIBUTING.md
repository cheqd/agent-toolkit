# Contributing

## Developer Certificate of Origin (DCO)

This project uses the [Developer Certificate of Origin](./DCO) v1.1. By contributing, you certify that you have the right to submit your contribution under this repository's licence.

**Every commit must carry a sign-off trailer:**

```
Signed-off-by: Your Name <your@email.com>
```

Add it automatically:

```bash
git commit -s -m "your commit message"
```

Commits without a sign-off will not be merged. CI checks this on every pull request.

To sign off commits you have already made:

```bash
git rebase --signoff main
```
